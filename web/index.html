Problema

Clasificación automática de noticias en español con técnicas de Procesamiento de Lenguaje Natural (NLP): categoría, tono y sentimiento.

Pipeline

  1. Preprocesamiento: normalización, tokenización, stopwords, lematización.
  2. Vectorización: TF-IDF con unigramas + bigramas.
  3. Análisis de sentimientos: léxico + RoBERTuito (Transformer).
  4. Clasificación: Naive Bayes + Logistic Regression vs. ELECTRA-small afinado.
  5. Detección de sensacionalismo: reglas léxicas.

Stack técnico

  • Naive Bayes
  • Logistic Regression
  • ELECTRA
  • RoBERTuito
  • transformers.js
  • GitHub Pages

Arquitectura

100% estática: toda la inferencia ocurre en el navegador. Naive Bayes y Logistic Regression usan pesos exportados a JSON. ELECTRA y RoBERTuito se cargan como ONNX con transformers.js. Sin backend en tiempo de ejecución.
